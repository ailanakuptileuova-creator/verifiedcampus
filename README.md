# verifiedcampus
AI-driven media verification platform for university credentials and campus workflows.
## Overview
Verified Campus is an automated authenticity verification system designed for higher education institutions. It protects academic ecosystems against AI-generated media manipulation, fake certificates, and duplicated submission files using real-time forensic analysis.

## Key Features
- AI Media Forensics: Detects deepfakes and AI-generated imagery using semantic CLIP evaluation.
- Perceptual Hashing (pHash): Identifies altered, cropped, or reused certificates and student submissions.
- Verification Index: Generates a real-time confidence score (0–100%) with actionable risk breakdown for admissions and faculty audit.
- REST API Integration: Easy integration with existing Learning Management Systems (LMS) and university portals.

## Tech Stack
- Frontend: React 18, TypeScript, Tailwind CSS, Lucide Icons
- Backend: Node.js, Express.js
- AI Engine Concept: OpenAI CLIP embeddings & Image pHash comparison algorithms
